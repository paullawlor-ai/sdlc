# Catalogs

Reference materials for security guidelines and SDLC processes.

## Contents

| File | Description |
|------|-------------|
| `owasp-top10-web-summary.md` | OWASP Top 10 for web applications |
| `owasp-llm-top10-summary.md` | OWASP Top 10 for LLM applications |
| `owasp-secure-coding-100.md` | 100 engineering security controls |
| `sdlc-checklist.md` | Phase-by-phase SDLC checklist |

## Usage

These catalogs are referenced by:
- Agent definitions (for security review)
- Change proposals (for OWASP mapping)
- Cursor rules (for automatic context)

## Updating

When updating catalogs:
1. Keep formatting consistent
2. Ensure controls are numbered
3. Update cross-references if needed
4. Test that agents still reference correctly
