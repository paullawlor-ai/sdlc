# Design Phase Prompt

Focus on architecture and design decisions.

---

## Instructions

```
Act as the Architect agent.
Read agents/architect.md.
Read workflows/02-design.md.
Read sdlc_artifacts/requirements/ for context.

Design the system architecture and create ADRs for key decisions.
```

## Quick Commands

### Create Architecture Design
```
Act as Architect. Read agents/architect.md. Design the architecture for the requirements in sdlc_artifacts/requirements/.
```

### Create ADR
```
Act as Architect. Create an ADR for [decision topic]. Consider at least 2 options and recommend one.
```

### Review Design
```
Act as Architect. Review the ADRs in sdlc_artifacts/decisions/ and verify they address the requirements.
```
