# Testing Phase Prompt

Focus on test planning and execution.

---

## Instructions

```
Act as the Tester agent.
Read agents/tester.md.
Read workflows/04-testing.md.
Read the acceptance criteria in sdlc_artifacts/requirements/.

Create a test plan and write tests to verify the implementation.
```

## Quick Commands

### Create Test Plan
```
Act as Tester. Read agents/tester.md. Create a test plan for [feature/change].
```

### Write Integration Tests
```
Act as Tester. Write integration tests for the acceptance criteria in [requirement doc].
```

### Run and Report Tests
```
Act as Tester. Execute the test plan and report results.
```
