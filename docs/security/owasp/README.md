# OWASP Reference Materials

This folder is for canonical OWASP documentation.

## Included Summaries

The `catalogs/` folder contains curated summaries:
- `owasp-top10-web-summary.md` - OWASP Top 10 for web applications
- `owasp-llm-top10-summary.md` - OWASP Top 10 for LLM applications
- `owasp-secure-coding-100.md` - 100 engineering controls
